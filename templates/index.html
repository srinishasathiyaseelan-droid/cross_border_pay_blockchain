⚙️ Core Technology Stack & Academic Implementation

Architecture Specs

1. Simulated KYC Module

Validates SME identity, government corporate ID, and jurisdiction before enabling payment capabilities.

2. Random Forest ML Model

Trained with Scikit-learn (fixed random_state=42) achieving 98.67% accuracy predicting Low, Medium, or High risk.

3. Smart Contract Engine

Written in Solidity (smart_contract.sol) and simulated locally. Enforces risk-based rules autonomously.

4. Cryptographic Blockchain

SHA-256 block hashing with Proof-of-Work nonces providing tamper-resistant settlement records.
